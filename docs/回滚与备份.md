# 回滚与备份

## 新的独立安装

本包使用项目名 llbot-compatible，不含现有服务器配置或自动覆盖脚本。已有同名项目时先检查，不要直接覆盖。启动前可用 `docker compose -p llbot-compatible ps -a` 核对。

停止本包实例：`docker compose down`。不要加 `-v`，不要手动删除state目录。账号资料、接口密钥在state目录；做冷备份时先停止本包实例，再将state与自己的compose配置以私有权限备份。

升级前保留原镜像ID、原compose与state冷备份。回退时先停止新实例，恢复原配置/原镜像与相应资料；同一QQ不得同时运行两套在线资料。恢复后分别检查真实QQ在线、PMHQ连接、接口认证和业务连接，不能把容器运行等同登录成功。

## 本次已部署的新机

原PMHQ容器、镜像、原配置和原资料冷备份已经保留，服务器专用回滚脚本有配置及容器身份守卫。本便携包不附带该机私有目录、原账号资料或SSH密钥，也不会自动登录或回滚任何服务器；请使用部署记录中的专用回滚入口。旧机未被操作。
